Mengapa GoldCast Berbeda?

Bukan sekadar regresi harga biasa. Model dirancang untuk menangkap interaksi antara tren teknikal emas dan kebijakan moneter global.

🧠

Arsitektur Stacked LSTM

Dua layer LSTM berurutan (24 units + 12 units) menangkap dependensi waktu jangka pendek dan jangka menengah dalam pergerakan harga emas mingguan.

📊

Integrasi Makroekonomi Riil

Menggunakan data resmi Federal Reserve (FRED) untuk Fed Funds Rate dan Non-Farm Payrolls yang secara fundamental menggerakkan likuiditas dan nilai tukar USD.

📐

Target Prediksi Berbasis Rasio

Memprediksi rasio harga (close_next / close_lag1) alih-alih nilai absolut. Mengurangi sensitivitas model terhadap non-stasioneritas data harga time series.

⚡

Inference Ultra Ringan

Forward pass LSTM diimplementasikan dengan pure NumPy (22KB weights). Tidak memerlukan TensorFlow runtime berat, response time dalam milidetik.

🔄

Auto-Fetch Data Terbaru

Mengambil data candle OHLC mingguan langsung dari Yahoo Finance API secara otomatis. Tanpa perlu input manual yang merepotkan.

📈

Backtest Riil 10 Minggu

Dashboard menyertakan tabel evaluasi performa model pada data historis terbaru lengkap dengan MAE, MAPE, dan akurasi arah (direction accuracy).

Alur Kerja Sistem

Proses data dari pasar global hingga menghasilkan prediksi harga akhir.

TAHAP 01

Ingesti Data Pasar

Candle mingguan emas (GC=F) ditarik otomatis, meliputi harga Open, High, Low, Close, dan Volume transaksi.

TAHAP 02

Sinkronisasi Makro

Nilai FFR dan perubahan NFP dari FRED diselaraskan secara temporal dengan candle mingguan menggunakan backward as-of merge.

TAHAP 03

Feature Engineering

Membentuk 9 fitur rasio dinamis (open/lag1, high/lag1, low/lag1, range/lag1, ffr, ffr_chg, nfp, ret_this, ret_lag2).

TAHAP 04

LSTM Inference

Sequence 4 minggu diskalakan via MinMaxScaler, diproses lewat jaringan LSTM, dan di-denormalisasi menjadi proyeksi harga final.
